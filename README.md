# Selah · Strong's Renderings

Renderings of the Strong's Hebrew lexicon entries into the Selah
project's supported languages — one directory per language, one
EDN file per entry, bucketed 500 to a directory
(`es/H0001-H0500/H0001.edn`).

Each entry carries the Hebrew headword and a prose rendering of
the Strong's definition in the target language, produced under the
Selah house discipline: divine Names transliterate, Hebrew stays
Hebrew, and every file's revision history is part of the work.

| Directory | Language |
|-----------|----------|
| `es/` | Español |
| `he/` | עברית |
| `pt/` | Português |
| `zh-Hans/` | 简体中文 |

English needs no directory here — Strong's (1890) is English and
public domain; the Selah English glosses live in
[selah-en](https://github.com/selah-project/selah-en).
